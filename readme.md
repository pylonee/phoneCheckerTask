# Определение оператора и региона по номеру телефона

## Установка
1. `pip install -r requirments.txt`
2. Сделать базу данных
3. Создать и заполнить .env
4. Скачать и положить в папку files файлы с данными (пока не работает обновление данных по сети.)
5. `python manage.py migrate`
6. `python manage.py update_data_local`
7. `python manage.py runserver`

## Возможности
Вывод оператора по введенному номеру телефона, если такой номер есть в базе. 

## Шаблон .env файла
SECRET_KEY=твой ключ django  
DB_NAME=имя бд  
DB_USER=юзер  
DB_PASSWORD=пароль  
DB_HOST=localhost  
DB_PORT=5432
